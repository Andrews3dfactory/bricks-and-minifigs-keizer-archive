                                                                                             ## Document Overview

                                                                                             ### `/docs/evidence/`
                                                                                             Primary source documents and reconstructed records.

                                                                                             | File | Description |
                                                                                             |------|-------------|
                                                                                             | `witness-statements.md` | Firsthand accounts from consignors, customers, and community members |
                                                                                             | `original-consignment-contract-reconstructed.md` | Full reconstruction of the original consignment agreement |
                                                                                             | `original-consignment-contract-summary.md` | Plain-language summary of key contract terms and obligations |
                                                                                             | `original-contract-analysis.md` | Clause-by-clause legal breakdown of contract terms |

                                                                                             ### `/docs/analysis/`
                                                                                             Research, pattern documentation, and behavioral analysis.

                                                                                             | File | Description |
                                                                                             |------|-------------|
                                                                                             | `legal-analysis.md` | Oregon statutory law analysis, breach claims, consumer protection |
                                                                                             | `franchise-patterns.md` | Documented patterns across Bricks & Minifigs franchise locations |
                                                                                             | `corporate-behavior.md` | Franchisor response patterns and corporate conduct documentation |

                                                                                             ### `/docs/media/`
                                                                                             Video evidence index and archived media links.

                                                                                             | File | Description |
                                                                                             |------|-------------|
                                                                                             | `MASTER-MEDIA-INDEX.md` | Master index of all media evidence with links and metadata |
                                                                                             | `bens-video-archive.md` | Ben's recorded video statements  links, summaries, timestamps |

                                                                                             ## Purpose & Disclaimer

                                                                                             This repository is maintained as a **public record archive** for community transparency, consumer protection advocacy, and potential legal reference. All documents are compiled in good faith from firsthand accounts, public records, and documented evidence.

                                                                                             This archive is **not** legal advice. Consult a licensed Oregon attorney for personalized legal guidance.
